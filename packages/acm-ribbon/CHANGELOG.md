# Changelog

## Unreleased

### Added

- Added the reusable ACM React ribbon foundation with configurable tabs, fixed-height panels, standard control sizes and accessible keyboard navigation.

### Changed

- Set the shared Ribbon typography to 16px regular tabs and 13px regular group and control labels, with 24px and 19.5px line heights respectively.
- Sized Ribbon tab underlines to their text at rest and kept unselected hover
  lines at label width. Hovering the selected tab widens its active line while
  retaining an inset from the tab edge; keyboard focus keeps the label-width line
  and visible focus outline without revealing a second button border. Removed
  the redundant full-width divider below the tabs.
