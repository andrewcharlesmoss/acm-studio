# Inter source for keyboard and heading lettering

Unmodified Inter v4.1 variable font from The Inter Project Authors.

- Source: https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable.ttf
- Licence: https://raw.githubusercontent.com/rsms/inter/v4.1/LICENSE.txt
- Local licence: LICENSE.txt (SIL OFL 1.1).

Used only by the development converter; the font is not needed or shipped at
runtime. The converter pins its SHA-256 and the specification records optical
sizing. Generated A, 3/£ and Ctrl artwork consists of filled vector outlines.

H1–H6 heading marks use the same pinned source, generated by
`scripts/generate-heading-lettering.py`. Their filled outlines retain Inter
letterforms, with weights 600/550/500 and cap heights 11/12/12.5 viewBox units
for Small/Medium/Large. No runtime font is needed.
