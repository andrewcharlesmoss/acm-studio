# Panel card

The Studio UI Library demonstrates the product-neutral PanelCard from @acm/panel
at /studio/ui/panels. The package owns the raised card surface, labelled
heading, optional eyebrow and description, header-actions slot, body and
optional footer. The component contract is v0.1.0.

The specimen uses fictional account details and temporary React state. It does
not call ACM Account APIs or read product storage. Consumers own panel placement,
width, resizing, visibility, data, permissions and commands. The Account Record
in ACM Account composes the same card with Account-owned content and actions.
